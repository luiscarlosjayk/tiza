# Tiza v0.1.0

**Draw on top of code in the terminal to explain it, step by step.**

Tiza is a terminal app for code walkthroughs. Open a file, draw boxes, arrows, highlights, notes and marks such as *move*, *read*, *write* or *drop* on top of it, group them into steps and present them live or export them. Agents can draw too, through a local API and an MCP server.

![Tiza explaining Rust ownership step by step](https://raw.githubusercontent.com/luiscarlosjayk/tiza/v0.1.0/docs/img/ownership.gif)

This is the first release for other people to use. Feedback and terminal reports are welcome in [Issues](https://github.com/luiscarlosjayk/tiza/issues).

## Highlights

- **Anchored to the text, not the screen.** Annotations survive scrolling, resizing and theme changes.
- **Steps and presentation mode.** `tiza demo.tiza --present`, named steps, auto-advance, and one stable layout per take, so the code never slides sideways between steps.
- **Follow mode.** `tiza src/main.rs --follow` reloads when you save in your editor, and the annotations follow their text.
- **Moves.** A step can insert, replace or delete lines, optionally typed out, and going back reverts them.
- **Exports from the same layout.** Text, Markdown, ANSI, SVG, PNG, animated GIF (nothing to install), MP4/WebM (with your own ffmpeg), asciicast and VHS tapes; `--all-steps` writes one image per step.
- **`tiza check`.** A preflight that lists every problem (clipped labels, lost annotations, broken moves) and the narrowest width where nothing is clipped.
- **For agents.** `tiza mcp` for Claude Code or any MCP client, a local socket API with published JSON Schemas, and a supervised mode where you approve each change an agent proposes while you present.
- **Made for video.** Dark and light themes checked for contrast after video compression, auto light/dark from your terminal, or your terminal's own palette with `--theme terminal`.
- **Local only.** No telemetry, no update check, no network code in the binary.

## Install

| Platform | Download |
|---|---|
| macOS, Apple Silicon | `tiza-v0.1.0-aarch64-apple-darwin.tar.gz` |
| macOS, Intel | `tiza-v0.1.0-x86_64-apple-darwin.tar.gz` |
| Linux x86_64 (glibc 2.35+: Ubuntu 22.04, Debian 12, Fedora 36 or newer) | `tiza-v0.1.0-x86_64-unknown-linux-gnu.tar.gz` |

```sh
shasum -a 256 -c tiza-v0.1.0-<target>.tar.gz.sha256    # or sha256sum -c on Linux
tar -xzf tiza-v0.1.0-<target>.tar.gz
cp tiza-v0.1.0-<target>/tiza ~/.local/bin/    # or anywhere on your PATH
```

**macOS:** the binaries are not signed with an Apple Developer ID. If you downloaded the tar.gz with a browser, macOS says *"tiza" Not Opened* the first time. Clear the download flag once with `xattr -d com.apple.quarantine ~/.local/bin/tiza`. A download with `curl` does not set that flag.

From crates.io or from this tag (Rust 1.88 or newer): `cargo install tiza`, or `cargo install --git https://github.com/luiscarlosjayk/tiza --tag v0.1.0 tiza`.

Windows is not supported in 0.x.

## Known limits

- Verified on macOS in Zed's terminal and in Herdr. Any terminal with 24-bit colour and Unicode box drawing should work; tmux and the others are untested ([Terminal support](https://github.com/luiscarlosjayk/tiza#terminal-support)).
- If a document is edited while Tiza is open, give moves a `find` target rather than a line number. The [CHANGELOG](https://github.com/luiscarlosjayk/tiza/blob/v0.1.0/CHANGELOG.md) lists the known limits of moves.
