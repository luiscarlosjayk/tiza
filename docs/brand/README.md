# Brand assets

These files are brand material for the repository page, an avatar and a social preview. They are not part of the `tiza` binary or of a crate.

| File | Size | What it is |
|---|---|---|
| `logo.svg` | 1200×400 | The logo: `> Tiza` and a striped cursor on a slate background. The hero image of the README (`docs/img/hero.png`) shows it, made from the paths of this file. |
| `logo.png` | 1200×400 | The same logo as a PNG, for places that do not show SVG. |
| `og-card.png` | 1280×640 | The social preview: the logo and the tagline on a chalk texture. Upload it in **Settings → Social preview** on GitHub. |
| `mark.svg` | 512×512 | The symbol `>` and the striped cursor, for an avatar. |
| `mark-small.svg` | 512×512 | The same symbol with a solid cursor, for a favicon of 16 to 32 pixels. |

## Colors

| Use | Color |
|---|---|
| Background (slate) | `#22272b` |
| Foreground (chalk) | `#f3f0e7` |

## Type and content

The word `Tiza` in the logo is made of outlines of Tiza Serif Bold, as paths. Tiza Serif is Libron, under the [SIL Open Font License 1.1](fonts/LICENSE-TizaSerif-Libron-OFL.txt). The SVG files do not need the font. [fonts/README.md](fonts/README.md) tells where the font comes from.

These files do not contain frames of Tiza. They are not screenshots or exports of the app.
