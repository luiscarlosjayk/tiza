# MCP tools

The MCP server gives these tools and resources.

Tools: `status`, `check` (the `tiza check --json` preflight of the live document; run it before showing one), `get_code`, `list_annotations`, `add_mark`, `define_style`, `list_kinds`, `add_arrow`, `add_box`, `add_note`, `add_callout`, `highlight`, `add_spotlight`, `update_annotation`, `delete_annotation`, `clear_annotations`, `add_move`, `delete_move`, `list_moves`, `set_step`, `next_step`, `prev_step`, `goto_step`, `set_focus`, `point_at`, `clear_pointer`, `set_theme`, `set_follow`, `render_text`, `export_image`. Anchors accept `{"find": "takes(s)"}` in addition to line and column, because an agent rarely knows the exact column; boxes, callouts and spotlights also take `find_start`/`find_end` (two texts that delimit the range, like Demo Time placeholders) instead of line numbers; `update_annotation` moves an existing annotation with the same anchors, keeping its kind and style. The server also publishes four MCP resources a client can attach as context without a tool call: `tiza://scene` (the document as JSON), `tiza://code` (numbered code), `tiza://render` (the current frame as text) and `tiza://render.md` (the frame in a Markdown fence). Full guide: [docs/agent-guide.md](../agent-guide.md). Ideas for what to show with an agent — a codebase tour, one agent explaining code to another, a review, a bug hunt — with a runnable tour of a four-file codebase: [docs/demos/scenarios.md](../demos/scenarios.md).
