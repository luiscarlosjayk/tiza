# tiza-export

Internal crate of [Tiza](https://github.com/luiscarlosjayk/tiza), published only so that `cargo install tiza` works. It has no stable API and can change in any release: use the `tiza` binary instead.

It holds Tiza's SVG, PNG and GIF export, with embedded fonts.

Install Tiza with `cargo install tiza`, or download a binary from [Releases](https://github.com/luiscarlosjayk/tiza/releases). Documentation: [README](https://github.com/luiscarlosjayk/tiza#readme).
