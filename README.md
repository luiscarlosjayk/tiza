# CodeDraw

Aplicación de escritorio para macOS, hecha en Rust con el crate [`gpui`](https://crates.io/crates/gpui). Es un clon de [Excalidraw](https://excalidraw.com) pensado como herramienta de apoyo para tutoriales de YouTube que explican código.

## Objetivo

Un lienzo de pizarra con estilo dibujado a mano, rápido y nativo en Mac, con las piezas que hacen falta para explicar código mientras se graba:

- Formas, flechas y texto, como en Excalidraw.
- Bloques de código con resaltado de sintaxis y anotaciones.
- Modo presentación para recorrer la explicación paso a paso.

## Estado

Proyecto en fase inicial. El plan de trabajo (épicas y tareas) vive en el board de CodeDraw.

## Stack

- Rust
- gpui (interfaz y render)
- macOS como plataforma principal
